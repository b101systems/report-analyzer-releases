# Report Analyzer Releases

Official Windows MSI releases for Report Analyzer.

Report Analyzer is a desktop tool for analyzing NI TestStand ATML reports. It imports the reports
produced by a test station and turns them into measurement history, capability indices (Cg, Cgk,
Cp, Cpk), Gage R&R studies and failure distributions, with PDF and Excel exports.

Download the installer from the [Releases](../../releases) page. Report Analyzer runs a 14-day
trial on first start; a license key activates it permanently on that machine.
